# Shared App Legal Pages

This directory contains reusable public privacy and support pages for apps published by Gopal Sorathiya. The repository is served through GitHub Pages using the `novyble.com` custom domain.

The public URLs are:

- Home: `https://novyble.com/app-legal/`
- Privacy policy: `https://novyble.com/app-legal/privacy/`
- Support: `https://novyble.com/app-legal/support/`

## Reusing for another app

Use the same privacy and support URLs in App Store Connect when the new app follows the general policy. If an app collects different data, uses additional SDKs, or requests different permissions, add an app-specific notice to `privacy/index.html` before publishing it.

Update the effective date whenever the policy changes materially.
